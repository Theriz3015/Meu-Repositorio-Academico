# Repositório Acadêmico | Análise e Desenvolvimento de Sistemas

## Sobre

Este repositório reúne minhas atividades acadêmicas, exercícios,
estudos e projetos desenvolvidos durante minha formação em
Análise e Desenvolvimento de Sistemas.

## Objetivo

Organizar e documentar minha evolução acadêmica e técnica,
facilitando a localização dos conteúdos desenvolvidos nas
diferentes Unidades Curriculares.

## Unidades Curriculares

- Gestão da Informação
- Inteligência Artificial
- Verificação e Validação de Software
- Desenvolvimento Fullstack
- Empreendedorismo
- Governança
- Tech English
- High Tech
- Projeto Integrador

## Organização

Os conteúdos estão organizados por Unidade Curricular.
Dentro de cada UC, as atividades podem ser separadas por
aulas, temas, projetos e materiais complementares.
